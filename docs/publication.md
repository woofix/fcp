# GitHub publication

[English](publication.md) · [Français](publication.fr.md)

The public repository is https://github.com/woofix/fcp.

Before publication, inspect tracked files and changes, verify Apache-2.0
notices, exclude private settings and data, run tests and build the image.
Never commit `.env`, `config/`, `data/`, `state/`, `geo/`, `logs/`, real email
messages or backups. Verify GitHub Actions after an approved push.
